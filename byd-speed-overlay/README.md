# عدّاد السرعة لسيارة BYD (ليوبارد 8)

تطبيق أندرويد لشاشة DiLink يعرض عدّاد سرعة عائماً فوق خرائط Waze المثبتة في السيارة.

## الميزات
- السرعة من حساسات السيارة عبر واجهة BYD الداخلية (`android.hardware.bydauto`)، وإن لم تتوفر يُستخدم GPS تلقائياً.
- زر واحد يشغّل العدّاد ويفتح Waze.
- عدّاد يمكن سحبه لأي مكان، ويتحول للأحمر عند تجاوز الحد المحدد.
- التحكم بحجم الرقم، وتشغيل تلقائي عند تشغيل السيارة.
- شاشة "فحص حساسات السيارة" تعرض ما تتيحه السيارة.

## التثبيت
1. انسخ `dist/BydSpeedOverlay-0.1.0.apk` إلى فلاشة USB.
2. افتحه من مدير الملفات في شاشة السيارة واسمح بالتثبيت.
3. افتح التطبيق، ثم امنح صلاحية "الظهور فوق التطبيقات" وصلاحية الموقع.

## البناء
```
./gradlew assembleRelease
```
يُبنى الملف تلقائياً أيضاً عبر GitHub Actions مع كل تعديل.
