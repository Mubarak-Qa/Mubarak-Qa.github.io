# مساعد السيارة: تطبيق لسيارة BYD ليوبارد 8

تطبيق أندرويد لشاشة DiLink، فيه ستة تبويبات:

| التبويب | المحتوى |
|---|---|
| **الرئيسية** | مؤشرات السيارة (السرعة، البطارية، الوقود، المدى، العدّاد، ضغط الإطارات…) والتحكم بالمكيف الأمامي والخلفي (الحرارة وقوة المروحة) وتدفئة وتبريد ومساج المقاعد |
| **عدّاد السرعة** | عدّاد عائم فوق Waze يقرأ من حساسات السيارة، وإن لم تتوفر يستخدم GPS |
| **الراديو** | محطات قطر والسعودية والإمارات والكويت والبحرين وعُمان (من دليل radio-browser.info المفتوح)، مع بحث ومفضلة وتشغيل في الخلفية |
| **الخلفيات** | خلفية الشاشة الوسطية، وصورة بملء الشاشة على شاشة الراكب |
| **تقسيم الشاشة** | فتح تطبيقين جنباً إلى جنب مع اختصارات محفوظة، أو فتح تطبيق على شاشة الراكب |
| **الإعدادات** | اللغة (عربي/English)، والسمة (فاتح/داكن)، والتحقق من التحديثات، وأدوات مطوّر السيارة |

## عن التحكم بالسيارة
BYD لا تنشر طريقة رسمية للتحكم بالسيارة. يستخدم التطبيق واجهات `android.hardware.bydauto` الداخلية عبر Reflection، وأسماء الأوامر فيه تقديرية لم تُختبر على ليوبارد 8.
- **الإعدادات ← أدوات مطوّر السيارة ← فحص** يعرض الأوامر المتاحة فعلياً في السيارة.
- يمكن تعديل ربط الأوامر بملف JSON من نفس الشاشة دون إعادة بناء التطبيق، والصيغة موثقة في `car/CarFeatures.kt`.

## التحديثات
زر "التحقق من التحديثات" يقرأ `version.json` من
`https://mubarak-qa.github.io/byd-speed-overlay/version.json`.
يعمل بعد دمج هذا الفرع في الفرع الذي تنشر منه GitHub Pages. لإصدار تحديث: ارفع `versionCode` في `app/build.gradle.kts`، وضع ملف APK في `dist/`، ثم حدّث `version.json`.

## البناء
```
./gradlew assembleRelease
```
