# مترجم التنبيهات الصينية · Chinese Alert Translator

تطبيق أندرويد يقرأ تنبيهات التطبيقات الصينية التي تختارها (مثل تطبيق BYD / 比亚迪)، ويترجمها، ثم يعرضها لك كتنبيه جديد بالعربي أو الإنجليزي. لا يعدّل على التطبيقات الأصلية ولا يتحكم فيها.

## المميزات (الإصدار 2.0)
- اختيار تطبيق واحد أو أكثر، أو ترجمة أي تنبيه صيني من كل التطبيقات.
- واجهة بالعربية أو الإنجليزية: زر **EN / ع** في الأعلى.
- وضع نهاري أو ليلي: زر **الشمس / الهلال** في الأعلى.
- لغة الترجمة: عربي أو إنجليزي.
- قاموس مخصص لأسماء الماركات والموديلات، مثل `方程豹=Fangchengbao`.
- ترجمة جوجل أونلاين، ومعها ترجمة على الجهاز تعمل بدون إنترنت كاحتياط.
- سجل لآخر التنبيهات المترجمة.

## التثبيت
1. ثبّت `release/CarAlertTranslator.apk`. يُثبَّت فوق الإصدار السابق مباشرة.
2. فعّل صلاحية قراءة التنبيهات من داخل التطبيق.
3. اختر التطبيقات المراد ترجمتها، أو فعّل خيار كل التطبيقات.
4. يُفضَّل استثناء التطبيق من توفير البطارية، وتنزيل نموذج الترجمة بدون إنترنت.

## البناء
```
./gradlew assembleRelease
```
